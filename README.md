# BhanuPrakash Ghatala — Product Management Portfolio

A personal portfolio inspired by the visual direction in the supplied Prakhar portfolio screenshots. The content is adapted to BhanuPrakash's resume and projects.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Sections
- Hero and personal introduction
- Selected product case studies: WhatsApp Pay, Zomato Group Ordering, TerraVision
- About and product-thinking interaction
- Product, analytics, design, AI, technical and collaboration toolkit
- Experience and leadership timeline
- Contact with LinkedIn and email

## Assets
- `public/bhanuprakash-original.jpeg` — original uploaded outdoor photo, used without AI retouching
- `public/BhanuPrakash-Ghatala-Resume.pdf` — resume download
